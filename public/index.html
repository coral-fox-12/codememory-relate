CodeMemory on Relate

The coding assistant that remembers the codebase — its memory is a Relate graph, not a flat list. Ask a question, or trace a symbol from its test to the decisions and gotchas behind it. Nothing is invented: if no memory matches, it says so.

DEMO build — memories here come from the bundled demo repo (clearly labelled DEMO) or from what you type. The store is a Relate single-file database (data/graph.rl); open it with relate --database ./data/graph.rl --read-only. See README.md.
